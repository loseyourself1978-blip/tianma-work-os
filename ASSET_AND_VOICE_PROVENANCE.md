# Character, runtime and sound provenance

TWOS bundles a fixed Nyra component whose manifest binds the source commit, event contract and every runtime resource hash. The canonical resource provenance is maintained in the [Nyra repository](https://github.com/loseyourself1978-blip/Nyra). Existing Owner-directed character art is retained; missing office/gala reclining and transition frames were generated for this authorized iteration. Generation does not establish exclusive copyright or eliminate third-party rights.

No external music, commercial voice clone, third-party pet pack or downloaded font is included. Nyra's short open/outfit WAV cues are procedural; their generation parameters and hashes accompany `audio/provenance.json`. Speech uses a user-selected installed macOS system voice, or explicitly imported local audio. Neither system voices nor user-imported recordings are redistributed in the package. Audio defaults to muted. No bespoke/exclusive AI voice is claimed.

Actual screenshots must come from a release candidate using non-sensitive engineering examples. A screenshot is not animation or workflow evidence. Any recording must be real, authorized screen capture; generated imagery is not a walkthrough video.
