## Four views

First use preserves Welcome, Owner setup, Project authorization and the complete
first-delivery guide. Saved valid inputs remain available; no automatic approval.
Daily work groups task/configuration, processing/decisions, and results/history.
Failure recovery presents its concrete reason beside the action, preserves the
failed record and allows only the existing safe retry. Completed work presents
its verified receipt and readable audit without a repeated execution request.

The three groups are navigation, not a promise of three clicks. Owner Review,
Approve, Run, Apply, Commit and independent Confirm Push remain distinct.
Configuration recovery does not mutate previous successful receipts or start
work. Missing dependencies remain honestly blocked until explicit recovery.
