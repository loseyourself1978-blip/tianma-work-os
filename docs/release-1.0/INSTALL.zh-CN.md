# 安装 Tianma Work OS 1.0.1

适用本次 TWOS/Nyra 联合候选 build 101.49。是否发布、签名和系统实测以发行回执为准；本机候选不等于已公开发行。

当前仅支持 macOS。Windows 版本开发中，尚无可下载版本。当前 TWOS 包为 Apple Silicon，工程实测为 macOS 27.0.1 / Safari 27.0.1。编译下限不代表所有旧系统都已测试，其他系统请先核对发行支持表。

1. 从对应 GitHub Release 下载 TWOS DMG，保留 manifest 和 SHA256SUMS。工单 ZIP、自动源码压缩包不是安装包。
2. 双击 DMG，将 **Tianma Work OS** 拖入 **Applications / 应用程序**。升级时先完成活动工作并正常退出旧 TWOS，再替换应用。本机环境数据不存放在 App 包内。
3. 推出 DMG，从应用程序启动。按 macOS 正常首次打开提示操作；若出现签名或安全阻止，先看故障排查，不关闭 Gatekeeper。
4. 配对工作台会打开。如先出现启动器，选择 **Window → ChatGPT + Codex**。TWOS 控件可通过 **语言 / Language → 中文** 切换，不会修改供应商网页账户语言。
5. 在选中的 ChatGPT、DeepSeek 或 Claude 官网页面登录自己的账号。TWOS 不内置账号或凭据，正常登录或真人验证由本人完成。
6. 本机执行时右栏选择 Codex，再点 **连接本机 Codex**。需事先安装并登录官方本机 Codex 应用；TWOS 使用其受支持的 App Server 连接。可用模型、额度与费用遵循你的供应商计划。
7. 点 **新建任务 / 会话**，选择“独立任务：使用空目录”或“已有项目：保留现有内容”。选择或新建目录，核对规范路径和读写范围后确认。仅选择目录不运行模型。
8. 在左侧讨论一项非敏感小需求，检查完整指令和目标。点 **交付 Codex 执行**，在右侧处理真实权限请求。接续有效绑定的已有会话无需重建目录。
9. 查看结果和真实成果卡片。“打开网页”“查看文件”“另存为…”“在 Finder 显示”分别执行对应操作；能打开不等于功能已验收。
10. 点顶部 **显示夜璃 / Show Nyra**。TWOS 已内置 Nyra 和资源，无需第二个安装包、Pets 插件、Python、Node 或联网下载画稿。声音默认静音。详见[操作指南](USER_GUIDE.zh-CN.md)。

**完成结束点：** 指定模型连接可用、目标任务可见、能找到其结果。不要为本指南重做已经接受的业务任务。

## 可选：原本机项目与邮箱账号

“原 TWOS 项目”保留原本机账号和项目服务，不是配对工作台的前置条件。首次使用该模式，按启动器给出的 Owner 初始化入口，授权独立工作区并创建本机账号。环境已配置发信时，点击注册，用自己的邮箱收取验证邮件，完成验证后登录；旧 Owner 可绑定邮箱而保留项目。如果发信未配置，应由环境维护者配置获准的发送服务，不假称已发邮件。供应商网站登录与该本机邮箱账号不同，安装包不包含开发者的发信密码。[原项目指南](../LEGACY_OWNER_GUIDE.md)仅适用于此模式。

高级校验可在下载文件夹运行 `shasum -a 256 -c SHA256SUMS`；普通安装不要求使用终端。
