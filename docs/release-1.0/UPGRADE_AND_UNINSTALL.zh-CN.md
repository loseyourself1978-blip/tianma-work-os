# 升级与卸载

**R2 验证范围。** 签名候选 TWOS 1.0.2 / 101.50 已通过一次明确启动的真实 ChatGPT↔Claude 三往返：六次提交及六份对应完整回复，没有逐轮手动发送或检查。重开后保留完成状态且不重放。TXT、PNG 和简单文字层 PDF 已取得双方向内容可读证据；原生／合成边界测试另列。匹配完整主回归、新字节公证和制品 hash 见发行回执；公开发行以对应 GitHub Release 为准，工程结果不代签 Owner 接受。

[R2 差量操作和准确边界](BIDIRECTIONAL_R2.zh-CN.md)。


先完成或明确停止自己的活动工作，正常退出 TWOS，再替换已验证的新 App，不修改运行中的包。本机环境、目录授权、草稿、供应商网站存储不是发行资产，不得复制进公开安装包。

内置 Nyra 固定版本；兼容且同签名的独立实例可复用显示控制，冲突会明确说明，不强退或降级。任务只读关联与浮窗显示分开报告。保留显示/静音偏好，不自动注册开机登录项。

卸载时退出并移除 TWOS App，不会同时删除独立 Nyra 或个人数据。可选数据删除应先备份并明确选择范围，不清空整个 Application Support 或浏览器数据。卸载 Nyra 默认保留偏好。重装不应重放已经完成的工作。
