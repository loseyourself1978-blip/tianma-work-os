# Nyra 单击返回、任务控制及左右共用 Codex 界面

候选：TWOS 1.0.10 / 101.58，Nyra 1.0.7 / 107。工单：TWOS-NYRA-FOCUS-AND-TASK-CONTROLS-R1。**当前为开发修改，最终打包 GUI 验证及发行仍未完成。** 本文不改变现有公开下载，也不代表 Owner 接受。

## 升级差量操作

匹配版本核验并正式提供后使用以下入口；无需重新制作已接受的业务成果。

1. 任一侧选择 Codex，使用相同的项目／聊天侧栏、消息区和输入区。从侧栏选择会话，不再使用会话下拉框；窄面板可折叠侧栏。模型、推理档位与输入模式仍保留各自用途。
2. 项目及聊天来自正式连接的可用元数据。未返回官方应用项目归属时，按目录归组并明确说明。TWOS 使用官方协议实现客户端，不是内嵌整个官方 App。读取历史不会接管官方 App 正在执行的轮次。
3. 最新公开活动按有界页面读取，以 item ID 去重。活动会话不能仅靠已保存轮次摘要更新；更早历史按需读取。读取失败保留原内容并说明新鲜度，不恢复或重跑任务；只展示公开进度摘要，不展示隐藏推理。
4. Nyra 连接后，单击人物可见区域，恢复准确绑定的 TWOS 工作台；拖动仍只移动人物。点击任务标题定位对应侧，目标变化时拒绝跳转至错误任务。只有宿主已激活、工作台实际可见、非最小化且取得 key 状态后，才确认显示成功。
5. 任务卡默认采用两行紧凑半透明气泡：长标题截断，悬停可看完整标题；编辑与停止图标直接可见，无需展开才能输入；箭头仅在双侧有任务时展开任务选择。气泡展示左右侧／提供方、可取得的会话标题及真实状态。无标题使用明确占位，过期时保留上一张卡并禁用不安全操作。“显示／隐藏当前任务”偏好仍保存；隐藏不会停止任务。
6. 单击 **编辑指令** 铅笔图标，直接打开取得键盘焦点的紧凑半透明输入框；目标固定，保留草稿并支持输入法组合。Enter 发送，Shift+Enter 换行，Esc 或关闭图标关闭而不发送。普通草稿自动保存，无需额外点击“保存草稿”。TWOS 控制的 Codex 轮次可选受支持的 Steer 或“当前任务完成后发送”；网页模型仅提供后者。选择和编辑不等于发送。已有附件需回 TWOS 核对，不由 Nyra 静默携带。
7. 选择待发指令仅修改尚未发出的内容；按 Enter 或箭头保存该修改，关闭则放弃未保存修改并保留原待发项，待发修改不会自动保存。已送达指令不覆盖。任务、目录、草稿版本或宿主改变时保留输入，拒绝改投。关闭输入框时保留目标；宿主可用时普通输入保存到 TWOS 草稿，取消待发项编辑保留原排队内容。
8. “停止”先撤销关联后续派发／自动接力，再中断准确的活动任务。“正在停止”不等于“已停止”，收到请求确认也不等于执行终态；未确认时明确说明。不回滚成果，不影响其他任务，迟到回复不重新启动队列。

升级差量到此结束，不继续进入首次使用全流程，不重跑已接受的出行网页或辩论。

## 权限与隐私

旧状态 socket 保持只读；单独的已认证用户控制 socket 仅支持 inspect、focus、draft、submit、editQueue、stop。双方校验同一用户、真实进程、准确应用及签名、实例、请求新鲜度和不透明任务标识。内置组件固定在签名 TWOS 中；首次连接独立版时，在 TWOS 选择“⋯ 更多 → 夜璃状态 → 连接并授权”。已有只读状态连接时，在该状态窗口点击“启用夜璃任务控制…”并确认同一授权。旧只读授权不自动获得控制权。

状态快照不含指令、代码、文件、账号或凭据。用户控制通道会传递本人选择编辑／发送的那一份草稿和补充，最大 64,000 UTF-8 字节；TWOS 使用原有本机草稿／队列／回执保存，并沿原授权提供方管道传递。Nyra 不取得自动批准、shell、文件访问、任意收件方或扩大目录权限。元数据诊断不写标题和正文。任务卡可能在屏幕显示有界会话标题，屏幕共享时可隐藏。

I/O 与签名核验不在 UI 主线程。请求使用四秒有界有效期，超时或连接重置立即失效；迟到身份核验不能继续发新操作。同一宿主生命周期内对修改类请求 ID 去重，重开或重连不重放未知送达操作。 明确发送后仅在有界时段只读核对同一任务回执，不再次发送。自动保存期间关闭输入框时，保留固定目标的编辑器直到保存确认；未确认的发送保留文字并禁用重复提交。

## 排障

- **发送／编辑结果未确认：** 再次发送被禁用，请保留编辑器并回 TWOS 核对原回执。草稿／发送进入控制通道前，夜璃先在本机保留最多一份恢复记录（最多 64,000 UTF-8 字节，仅当前用户可读写）。匹配的保存或投递确认后清除；旧回调不能删除更新记录。重开后的恢复文字只能查看和复制，禁止自动发送或写入新任务。请在 TWOS 核对原任务；“使用 TWOS 草稿”会先确认丢弃恢复文字，再读取当前草稿。该记录不是第二个队列，未提交的输入法候选字及自动保存前的按键不宣称已可靠落盘。
- **任务已变化／草稿保留：** 回 TWOS 核对目标并明确选择，不自动改投。
- **只读或不可用：** 官方 App 仍控制该轮次、独立版没有控制授权、旧宿主不支持，或接口未暴露当前状态。读取历史与执行控制分开，使用原连接／授权入口，不删除凭据。
- **停止未确认：** 核对准确任务的状态，不反复向其他任务发送停止，也不强退官方应用。
- **窗口显示未确认：** 尚未观察到绑定工作台实际置前，正常打开正确 TWOS 并核对连接；不会按任意路径或同名应用启动副本。
- **最新聊天滞后：** 查看只读更新时间并刷新。有界 item 读取不需要 thread/resume，也不发送模型任务。

当前仅支持 macOS；Windows 开发中，没有可下载版本。原五套服装、声音和已接受业务结果保留。

新轮次开始时，任务选择仍保持同一会话。没有真实运行的登录页或起始页不会成为任务卡。已控制的执行结束后仍可编辑并保存草稿，不会暗中开始下一轮。

输入框支持标准剪切、复制、粘贴和全选快捷键，作用于当前有焦点的原生编辑器。发送被拒绝或回执不确定时，可直接查看保留文本并在核对 TWOS 回执后明确选择使用 TWOS 草稿，无需重启 Nyra。临时连接／状态待核不会被描述为原任务控制权限丢失，也不会自动重发。此新增路径仍需最终候选实际 GUI 验证。
