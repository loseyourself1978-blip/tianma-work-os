# 本机 Codex 连接与夜璃任务标签

候选：TWOS 1.0.7 / build 101.55；Nyra 1.0.6 / build 106。当前为本机候选，不等于已发布或 Owner 接受。

## A · 升级差量检查——完成即结束

TWOS 右侧选 Codex，单击一次“连接本机 Codex”。连接时显示当前阶段，可用“取消连接”；确认认证及目录列表后显示模型和会话。连接本身不发送任务。选择原会话并核对目录，再按需要明确发送。“断开连接”后重新连接会保留草稿和历史；送达未知的执行先对账，不重放。

夜璃人物下方最多显示两行当前任务，例如 `ChatGPT: 当前会话标题`、`Claude: 当前会话标题`。仅显示新鲜且正在工作、排队或等待操作的面板。标题来自所选会话的可见标题，不是模型生成的摘要；取不到标题时明确显示“当前任务／等待你的操作”。空闲或状态过期后收起。

通过夜璃菜单“显示当前任务”或展开控制环中的文字气泡按钮，显示／隐藏标签，重启保留偏好。单击人物（不要拖动）或任务标签，返回刚核验的当前 TWOS 应用。拖动仍只移动人物，不跳转。点击不发送、批准、停止或重启任务；无法核验宿主时提示重新连接，不随意打开其他应用。

不重做已接受的出行网页、辩论、换装或声音验收。本次差量检查到此结束，首次使用和接续任务仍按各自指南操作。

## 排障与权限边界

找不到 Codex：正常安装或修复官方本机桌面应用。需要登录：在官方应用正常登录后明确重连。超时、异常 JSONL 或子进程退出均有具体错误；等待本次自建子进程结束后可再次连接。不重发状态未知的任务，不终止无关官方应用或进程。

进程启动、管道读写、JSONL 分帧及解码均移出主界面队列，保留期限、缓冲区上限、连接代次、防双击和过期回调拒绝。这不代表承诺网络或模型响应速度。

夜璃通过已认证的本机只读通道接收原有最小活动状态，以及最多两条、每条 90 字以内的活动会话标题。不发送提示词、回复、附件、路径、账号、凭据或代码。标题仅留内存，不写播放／可见性诊断；隐藏标签只隐藏展示，断开状态连接会停止读取。点击人物会独立重新核验同一签名宿主，不给状态通道增加执行指令权限。

仅支持 macOS；Windows 开发中，无下载。现有安装和回退包保留。签名、公证及最终包真实界面结果，以本轮热修复回执为准，分别记录模拟检查和 Owner 接受。
