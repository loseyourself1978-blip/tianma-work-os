# 英文动作语音：tiny-voca F2

匹配版本：独立夜璃 1.0.8／108，与 TWOS 1.0.11／101.59 内置版同步。发布状态和实际播放验证以最终发行回执为准。

中文保留原有 13 段小田 1413 录音，字节不变。英文默认改为 tiny-voca F2 美式女声的 13 段离线录音，与问候、休息、工作、等待确认、庆祝、鼓励、换装、挥手、待机、阅读、移动、跳跃、落定一一对应。

声音 → English → **tiny-voca F2 · English (US) · bundled cues**。取消静音后可试听；开启“跟随动作说话”后，在符合条件的动作变化时播放。明确选择过的系统声线和自定义导入音频保留，导入音频优先。隐藏、静音、停止会停止播放；冷却、去重和真实任务终态规则不变。英文资源缺失或损坏会报错，不用中文冒充英文。

语音在开发时使用固定版本的公开 ONNX 模型生成。App 只带约 1.6 MB 的 WAV 短句，不要求用户安装模型或推理环境，不增加联网合成或订阅，不朗读任务正文，也不把对话交给语音服务。无需新增麦克风、模型或网络权限。F2 为合成声线，不宣称是独家音色或真人克隆。

来源：[tiny-voca](https://github.com/n4ze3m/tiny-voca)、[模型与音色说明](https://huggingface.co/n4ze3m/tiny-voca)。代码和模型采用 Apache-2.0；随包保留授权文本和发音数据声明。清单记录模型版本与哈希、F2、0.95 语速、原音调、24kHz 单声道 PCM 及各短句 SHA-256。信号检查、实际播放和 Owner 听感接受分别记录。再生成材料见 Nyra 源码 `docs/voice-generation/README.md`。
