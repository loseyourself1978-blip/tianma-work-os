# Troubleshooting

**R2 verification scope.** The signed TWOS 1.0.2 / 101.50 candidate completed one explicitly started three-round-trip exchange between real ChatGPT and Claude webpages: six submissions and six matched complete replies, with no manual per-turn send or check. Reopening preserved the completed exchange without replay. TXT, PNG and simple text-layer PDF readability was observed in both directions; native/synthetic boundary checks are recorded separately. The matching complete main regression and new notarization are recorded in the release receipt; the linked GitHub Release records publication. These observations do not grant Owner acceptance.

[R2 incremental instructions and exact boundaries](BIDIRECTIONAL_R2.en.md).


- **macOS blocks installation:** verify the exact release and hash/signature receipt. Do not disable Gatekeeper or remove quarantine. An unnotarized engineering candidate is not the default public installation path.
- **Login/challenge:** finish it yourself on the actual provider page. TWOS does not solve CAPTCHA, copy cookies, or replace web access with a billed API. Safari fallback is not proof of embedded success.
- **Codex not connected:** confirm the official local runtime is installed and signed in; reconnect using the product control. Shared history does not grant two clients control of one active turn. Do not start a second copy of uncertain work.
- **Folder/attachment rejected:** check the displayed canonical scope and error. Do not widen access to unrelated directories. Unsupported file content is not silently treated as read.
- **Nyra status unknown:** the character can remain interactive while its read-only endpoint is unavailable. Open the parent TWOS; inspect connection details. Directory permission waits must not freeze animation. Grant only the specific normal macOS folder prompt if appropriate; never grant full disk access for this feature.
- **Nyra hidden/offscreen:** use Show Nyra or its menu-bar Show/Reset position. Version conflicts are explained; do not kill unrelated apps. Manual preview ends and resumes the real state.
- **No estimate:** insufficient steps/history, waiting or stale connection is a valid reason. Refresh status observes only; it does not restart the task.

For a report include app version, non-sensitive error text and action taken. Exclude cookies, credentials, private chats and business artifacts.

### App moved or macOS translocated it

The read-only link is bound to the exact signed producer, including its application path. Moving/replacing TWOS, or macOS running a quarantined copy from a different temporary path, can leave standalone Nyra at NOT_CONNECTED while Show/Hide still works. Install the verified app in Applications, open that version, then use **Nyra status → Connect** to explicitly renew the read-only association if needed. Do not delete preferences or disable Gatekeeper. In the final isolated installer check, a changed macOS translocation path correctly invalidated the old link; that case is not claimed as automatic reconnection.
