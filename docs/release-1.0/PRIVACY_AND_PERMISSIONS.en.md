# Privacy, permissions and cost

TWOS hosts official provider websites and a local Codex App Server client. Each provider applies its own account, retention, plan and usage terms. TWOS does not merge all visible services into one quota pool or silently switch billing paths. No credits, resets or subscriptions are purchased automatically.

Only explicitly selected handoff text/attachments should be sent to the bound destination. Choosing a folder does not authorize reading all its contents. Local execution is restricted to the confirmed scope, with real approval requests retained. HTML artifacts open outside the product's authenticated page/native bridge.

Nyra receives only bounded read-only state and opaque correlation identifiers: no chat body, source code, account, credentials or business ledger. It cannot execute, approve, trade or send messages. Signature and peer identity checks remain in place. Local preferences are separate from application code. Diagnostic publication must remove private content.

The pet does not require Accessibility, full-disk, microphone, screen-recording or global keyboard permissions for ordinary local animation. A directory prompt may occur when the user selects a protected folder. Screenshots/recordings are separate user-authorized actions. No startup login item is silently created.
