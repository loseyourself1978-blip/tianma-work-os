# R4 验证口径

STATIC：源码与权限边界；SIMULATED：真实 WebKit 上的明确测试页面及事件样本；REAL_GUI：专用 ChatGPT／Claude 工程会话及本机控件；OWNER_CONFIRMED：此前有限 Nyra／辩论接受。上述证据不互相替代。

R4 工程记录包含单侧勾选驱动双方至少三个真实往返、双方原生停止、宿主停止、生成中勾选、手动在途接续、明确文本附件上传／内容回读，以及 Nyra 尺寸与帧推进。精确候选、最终整批测试数量、覆盖与限制由发行回执记录；历史 R3 数量不是 R4 门禁。

真实竞态观察与模拟确定性竞态分别保留；没有观测到的鼠标／时序不写成实测。停止不能撤回在途内容；未知投递保持未知并先只读核对。仅完全匹配的稳定输入完整绿色门禁允许实施 PASS。新 UI Owner 接受仍独立待定。

重启专项发现：网页补载历史改变了按列表位置生成的备用消息标识，已发送回复重新出现 Send；未执行重复发送。修复优先使用公开消息 ID，否则仅对当前回复及其前置用户消息生成 SHA-256 标识。旧位置型回执内容相同时按身份不明确阻止重发，保留原记录，不宣称新消息已送达。定向与最终打包验证分别记录。

停止后接续：已停止循环中的未核验回执，不再全局阻塞用户明确选择的另一条完整回复。原目标仍打开时，先只读核对旧投递；保留旧回执及不确定状态，再对新选择执行同样的逐消息防重复与目标预检。已消费的回复只等待新内容，不重发旧轮次；暂停中的执行仍保持原绑定范围。
