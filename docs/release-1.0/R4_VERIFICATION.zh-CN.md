重启专项发现：网页补载历史改变了按列表位置生成的备用消息标识，已发送回复重新出现 Send；未执行重复发送。修复优先使用公开消息 ID，否则仅对当前回复及其前置用户消息生成 SHA-256 标识。旧位置型回执内容相同时按身份不明确阻止重发，保留原记录，不宣称新消息已送达。定向与最终打包验证分别记录。

停止后接续：已停止循环中的未核验回执，不再全局阻塞用户明确选择的另一条完整回复。原目标仍打开时，先只读核对旧投递；保留旧回执及不确定状态，再对新选择执行同样的逐消息防重复与目标预检。已消费的回复只等待新内容，不重发旧轮次；暂停中的执行仍保持原绑定范围。

最终打包 GUI 另发现启动窗口的语言未传播到已打开双栏：保存后启动窗口已切换，双栏仍保留原语言。现已在成功保存及观察到偏好改变时刷新现有工作台。真实 Cocoa/WebKit 测试样本验证控件文案、偏好保存、路由不变和零派发；最终打包 GUI 复核单独记录。
