# 简洁任务状态、准确宿主聚焦与英文语音：核验记录

范围：2026 年 11 月 17 日 TWOS 1.0.11 / 101.59 与 Nyra 1.0.8 / 108。工程证据和 Owner 接受分别记录，是否公开下载以匹配 GitHub Release 为准。

## 实际原因与差量

现场人物来自上一轮工程 Nyra，绑定的准确 TWOS 安装路径与当前正式版不同；当前安装版拒绝接管该无关实例符合身份校验。Owner 正常退出旧实例、从安装版显示 Nyra 后，确认人物单击可以返回。该证据解释此次安装混用，不解释所有历史漏点。

源码另外确认了两项耦合：默认任务展示依赖控制通道任务列表且保留已结束行；人物返回也走同一任务控制客户端。操作诊断还能残留于人物上方 detail。修复将可信只读状态、仅宿主聚焦和任务修改分开。默认气泡只显示当前活动，短暂失联有有限宽限期，确认空闲／终态后收起；人物顶部不再常驻诊断。实际草稿及未知送达记录保留。

真实匿名 ChatGPT 工程会话又暴露 `/uc/…` 被可恢复目标 URL 过滤器排除的问题。新增准确域名的只读活动 URL 识别，未将匿名会话扩大为可恢复交接或可编辑目标。提供方通用首页标题改用“正在回复”等本地化活动占位，不调用模型总结、不借用旧消息。

普通人物返回不依赖任务、轮次或编辑授权，仍核对同一用户、准确签名应用、活动对端和宿主实例；I/O 与身份校验在主线程外。宿主恢复自己的工作台，并核验实际可见、非最小化、激活／焦点和遮挡状态，不按显示名称误开另一副本。操作有界完成／报错后释放 pending；修改操作的权限及任务／轮次／请求绑定保持严格。

## 语音与资源

两款产品使用同一固定 Nyra 代码／资源；五套服装图均与最终运行时 SHA-256 相符。中文 13 段小田 1413 录音逐字节未变；英文为一一对应的 13 段 tiny-voca F2 美式英语离线短句。双语 26 个动作文件可解码；英文 PCM 有效、非静音且无削波样本。实际英文试听及动作短句进入原生播放器，这些检查不代替 Owner 对音色的主观接受。

App 仅包含约 1.6 MB 英文 WAV、上游声明和来源记录，不包含语音模型、模型下载、推理服务或新增计费；不合成或发送对话正文。明确导入音频、静音及播放冷却机制保留。
