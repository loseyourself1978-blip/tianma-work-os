# Upgrade and uninstall

**R2 verification scope.** The signed TWOS 1.0.2 / 101.50 candidate completed one explicitly started three-round-trip exchange between real ChatGPT and Claude webpages: six submissions and six matched complete replies, with no manual per-turn send or check. Reopening preserved the completed exchange without replay. TXT, PNG and simple text-layer PDF readability was observed in both directions; native/synthetic boundary checks are recorded separately. The matching complete main regression and new notarization are recorded in the release receipt; the linked GitHub Release records publication. These observations do not grant Owner acceptance.

[R2 incremental instructions and exact boundaries](BIDIRECTIONAL_R2.en.md).


Finish or explicitly stop your own active work. Quit TWOS normally, then replace its application with the verified release. Do not edit the running bundle. Existing local environments, directory authorizations, drafts and provider website stores are not release assets and must not be copied into a public package.

The bundled Nyra has a pinned version. A compatible, same-signer standalone instance is reused for visibility control; conflicting versions are reported, not killed or downgraded. Read-only task binding is reported separately from display. Existing visibility/mute preferences are respected. No login item is registered automatically.

To uninstall, quit and remove the TWOS application. This does not remove standalone Nyra or personal data. Optional data deletion is separate: back up needed work and deliberately choose what to remove. Do not delete all Application Support or browser data. Removing Nyra itself leaves its preferences unless you explicitly remove them. Reinstalling is not a reason to replay completed work.
