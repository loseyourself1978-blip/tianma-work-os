# TWOS 1.0.4 / 101.52 — 精简交接

适用于本轮 R4 候选及其固定内置 Nyra 1.0.3 / 103。构建、完整门禁、签名、公证和发布状态以匹配发行回执为准，本指南本身不代替验证。

Owner 的“nyra、辩论验收通过”作为此前功能的有限接受保留。无需重做旧辩论、出行网页、换装或透明素材；整体 20.2 和新 UI 不因此自动通过。

## A · 已有用户升级后，只检查新入口

进入条件：安装前核对匹配发行回执、签名、公证和下载 hash。正常退出旧 TWOS／Nyra，再替换所需 App。TWOS 内置匹配 Nyra，不需要另外安装桌宠。保留原登录、聊天、草稿、目录权限和宠物偏好。

1. 在两个已选定的网页会话中正常聊天。回复思考、生成或工具运行时，不出现当前回复的发送或核验卡；确认完整后，该侧仅出现一个“发送到 {对侧提供方}”。点击一次即可；“已发送”是回执，不需要再点 Check delivery。
2. 若要双方连续交流，勾选任意一侧的“自动发送回复到 {对侧提供方}”。两侧同步勾选，以被操作侧的当前新回复为起点。还在生成就等待完整，没有新回复就等待；已交接的回复先核对原回执，不重复发送。没有角色、首轮正文、轮数或分钟表单。
3. 在任意一侧点击原按钮位置的“停止自动发送”，或取消任意侧勾选。网站自身的停止也停止双方后续派发。等待间隙同样能停。已经发出去的消息不能撤回，迟到回复不会再触发下一轮。重开 App 后自动发送保持关闭。
4. “⋯ 更多”内保留在 Safari 打开、原 TWOS 项目、附件选择／清除、交接记录和诊断。只有明确选中的文件参与交接，路径或文件名不是已上传的证据。附件变更前先停自动发送。
5. Nyra 悬停只保留“＋／展开”和真正的全屏按钮。展开后可明确选择“放大／缩小／恢复默认大小”；滚轮／触控板缩放保留。不会再出现尺子／方块缩放手柄或其隐藏命中区。

完成结束点：只反馈上述新入口的可见性和操作；不要继续下面的首次使用流程，也无需重新证明已接受业务。新 UI 接受由 Owner 决定。

## B · 首次使用

仅在第一次使用时执行。先按匹配安装指南核对 macOS 版本、架构和 SHA-256，安装签名、公证后的 TWOS。在官方网页直接登录所需账号；正常登录／真人验证由本人完成，TWOS 不复制账号凭据。

选定两侧提供方及具体会话，正常聊天。完整回复后点击其下方 Send，或勾选自动发送后在任意侧停止。Codex 本机文件执行仍须独立目录及原有批准；网页自动聊天不会授予文件、命令、审批或 Git 权限。原本机项目如需邮箱注册、验证或登录，沿用原指南，不改变已登录账号。

完成结束点：理解发送范围、接收方和停止入口即可；不要求制造演示网页或重复报告。

## C · 接续已有工作

选择原提供方和原会话，保留已有草稿、附件记录及目录绑定。刷新／重开只读回状态，不重放旧任务。自动交换默认关闭；只有新的明确勾选才能接续。若有未知投递，在“更多 → 交接记录”展开详情核验；检查动作本身不重发。

已有匹配手动交接在途时，勾选自动发送先对账并接续其真实回复。旧题、新题和排错信息不能仅按“最后一段文字”混用。若目标变化、登录／验证、额度限制、草稿冲突、文件缺失或回声导致暂停，先处理显示的具体原因，再明确继续。

## 权限、结果和排障

本功能使用已有 WKWebView 官方网站交互及原 Codex App Server 连接，不是嵌入完整官方 Codex 图形界面。一次手动发送或共享自动会话只冻结被选定的正文身份、版本、hash、文件范围与两侧目标。对方回复不能扩张权限或接收方；不自动购买、充值或转换 API 计费。

未知或中断回复不会强行标完整。投递未知先对账；登录／验证按网站正常流程完成。执行通道结束、业务结果、验证与 Owner 接受互相独立。Nyra 只读取最小状态，不读取正文、文件内容、账号或凭据，也不能执行或批准任务。

如果按钮没有出现，先看回复是否仍在生成、是否中断，或是否显示活动识别原因；不要反复点击顶部，因为顶部发送已移除。需要更多证据时使用详情或“更多 → 交接记录”。停止后仍有在途回复属于真实已发送状态，不代表又派发了一轮。

当前仅支持 macOS；Windows 开发中，无可下载版本。对应界面媒体及测量范围见 MEDIA.zh-CN.md 和匹配回执；旧 R3 截图只作历史记录，不能证明 R4 UI。

## 工作台语言与夜璃显示

顶部直接显示 **Language: English / 语言：简体中文** 选择器，切换后 TWOS 控件立即更新并保存偏好。不会改变提供方账号语言、任务正文、聊天或文件，不会发送任务。

**显示夜璃／隐藏夜璃** 跟随实际内置浮窗状态。若另一安装位置的夜璃仍在运行，会明确显示冲突，不把它当成已隐藏；从该夜璃自己的菜单正常退出后，再显示当前内置组件。不会停止任务。
