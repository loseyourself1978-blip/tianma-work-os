## Discussion, handoff and outcomes

The service selectors bind the actual destination. Select only the intended text/attachments. A ready supported web target can submit with one click. Draft-only, login, challenge and uncertain delivery are explicit states; uncertain delivery must be reconciled rather than blindly resent. Web providers can return code but do not thereby create local files. A later Codex file-writing request is a separate handoff. TWOS uses native WKWebView and an App Server client, not an embedded official Codex macOS GUI.

Expand actual tool activity, commands, output, diffs and approvals in the right pane. Usage separates account windows from locally observed task tokens. Elapsed time is observed run time, not billed compute time. ETA is a labelled local estimate or an explanation that evidence is insufficient. Completion of transport, business result, verification and Owner acceptance remain distinct.

A file card may offer **Open webpage** (trusted host opens the exact authorized file), **View file** (read), **Save as…** (choose a copy destination), or **Show in Finder** (locate the original). A one-file task correctly has one artifact. Untrusted HTML runs outside the authenticated product page/native bridge.

## Nyra

Click **Show Nyra / Hide Nyra**. Enter the character to jump once; drag left/right for matching running frames and release to settle. The control ring and stage use the same bounded manual preview actions. Previewing Celebrate is not business success.

Black & purple, Office and Gala support standing and reclining. **Stage** opens a transparent screen-sized stage; **Pose** changes stance. Runs/jumps from reclining use same-outfit rise/action/lower frames. Blank areas pass pointer input through. **Desktop** or Esc while stage-focused restores saved position, scale and outfit. Hiding/quitting also restores desktop configuration. No global keyboard interception is used.

Nyra consumes minimal read-only state. Idle, running, queued/waiting, partial/failure/cancellation and disconnected remain distinguishable. Unverified completion does not celebrate. An explicitly checked, exactly bound result may trigger one celebration, without changing an earlier executor PARTIAL report or granting overall product acceptance. Reconnection does not replay celebrations.

Sound is muted by default; explicit system speech/imported voice and procedural cues are described in provenance. No exclusive AI voice is shipped. Hiding stops animation/audio work; quitting TWOS does not kill a separately used Nyra.
