# 故障排查

**R2 候选说明，不能作为已发行或真实 GUI 通过回执。** 原生及合成页面回归单独记录；真实提供方往返、附件和最终打包界面检查，须以匹配回执为准，当前仍待完成。

[R2 差量操作和准确边界](BIDIRECTIONAL_R2.zh-CN.md)。


- **系统阻止安装：** 核对对应 Release、哈希和签名回执，不关闭 Gatekeeper、不移除隔离标记。未公证工程候选不等于面向新手的正式安装路径。
- **登录/验证：** 本人在实际供应商网页正常完成。TWOS 不代解验证码、不搬 Cookie、不私自换成计费 API。Safari 降级成功不能替代内嵌通过。
- **Codex 未连接：** 确认官方本机运行时已安装登录，再使用产品重连。共享历史不代表双客户端能同时控制活动 turn；未知执行不要另起副本。
- **目录/附件拒绝：** 核对界面规范路径、范围和具体错误，不扩大到无关目录。不支持的正文不会被假称已读取。
- **Nyra 状态未知：** 只读端点不可用时仍应能互动。打开所属 TWOS 并检查连接详情；目录权限等待不应冻住动画。确需访问时只处理相应 macOS 文件夹提示，不为此授予全盘权限。
- **隐藏/找不到人物：** 使用顶部显示或菜单栏显示/重置位置。版本冲突会说明，不强退其他 App。手动试播结束后恢复真实状态。
- **没有 ETA：** 步骤/历史不足、等待或连接过期均会说明。刷新状态只观察，不重跑任务。

反馈请提供版本、非敏感错误和操作，不附 Cookie、密码、私人聊天或业务成果。
