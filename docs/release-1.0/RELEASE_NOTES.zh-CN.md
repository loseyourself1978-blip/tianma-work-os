## A · 只做本次升级差量检查

1. 新候选可用后，正常退出旧应用，再用对应 DMG 替换。保留原配置与网页登录，不清除网站存储，不重建已接受任务。
2. 两个选定会话中，完整普通回复下显示与对侧一致的“发送到 Claude／发送到 ChatGPT”。支持标题、段落、列表、表格及代码。“查看本次发送内容”显示该条准确正文。完整性未知时，入口保留并说明原因，可“重新检查回复状态”；不会发送半段回答。最新一轮已停止时，不拿旧辩题替代；明确选择的历史完整回复仍保留自身身份。
3. 打开“自动互聊”，点“使用左侧最新完整回复”或填写新首轮，核对双方会话、角色及精确附件。选择轮次／时间预算，或“直到你停止 · 不设轮次或时间上限”，只点一次“开始自动互聊”。无需手动预跑一轮。投递未知、登录验证、服务限制或目标变化时暂停，不盲重试。
4. 任一侧网站原生“停止”会先停止自动后续派发；两侧工具栏也各有“停止自动互聊”，互聊窗口有“停止后续互聊”。宿主停止不冒称取消网站已经开始的生成。在途消息保留回执；网站明确中断的回复不能作为完整回复转发。“检查投递”仅核验、不重发。重启保留停止状态，接续必须明确操作。
5. “夜璃状态”分别显示当前可见 consumer 的传输连接、左右活动／原因／新鲜度，以及实际动画 clip 和帧推进。已连接但活动未知属于活动识别问题，不写成传输断连。任一侧工作时保持工作动画；两侧新鲜且确认空闲才待机。悬停／拖动短动作结束恢复真实基础状态，未核验网页回复不庆祝。

**完成差量检查后到此结束。** 不重做出行、LDD、已保存成果或 Open/View/Save/Finder 接受。新的 Owner 差量结果与实现验证、公开发布分别记录。

## B · 首次使用

沿用安装与首次任务指南，核对服务和会话，正常登录，只选择本次要共享的指令／文件。网页回答不能授予本机文件、命令、批准或 Git 权限。TWOS 已内置夜璃，无需另装桌宠。

## C · 接续已有任务

回到原会话和保留的回执。投递未知先检查，再决定新提交。完成／停止历史不是新的启动授权。新用户问题不能被静默替换成另一侧旧回复。

## 诊断与证据边界

隔离真实 ChatGPT 页面暴露“你说：You”“ChatGPT 说：ChatGPT”双语标题，同时没有旧消息 ID。旧精确标题规则把多条回复合并为最后一条。R3 让卡片、选择和对账共用准确的输入框／消息边界。隐藏兼容输入和嵌套编辑层不再造成虚假歧义；真正多个独立输入仍保持未知并解释。这一实测机制及合成歧义用例不等于已捕获 Owner 原页面的全部细节。

ChatGPT“已停止思考”与 Claude“回复已中断”仅在准确匹配的轮次中构成中断证据；正文引用不是停止指令。投递、完整回复、业务核验和 Owner 接受仍是不同事实。

Nyra v3 在原认证最小协议上只增加来源侧状态、受限原因和新鲜度。consumer 实例、最后收到快照、最后状态变化、实际 clip 与累计帧推进可分别查看。同值快照刷新连接活性，不把动画反复重置首帧；签名与精确对端检查保留。不会向夜璃发送聊天、附件字节、路径、代码、账户或凭据。

当前仅支持 macOS。Windows 开发中，尚无可下载版本。既有素材、服装、透明舞台、顶部安全区控件及声音范围保持；实际测试平台、最终源码、签名及哈希以匹配发行回执为准。

## R2 差量操作

本版为 TWOS 1.0.2 / build 101.50，内置 Nyra 1.0.1 / build 101。不要替换正在运行的 App。既有接受、登录、目录权限、草稿和已结束辩论均保留；不会自动恢复旧辩论。

### 手动双向交接

1. 分别选择两侧提供方和具体会话。新功能使用专用非敏感工程会话检查，不重跑旧业务。
2. 等待源回复完整结束。顶部“发送到［提供方］”发送明确选中的回复文字；未选中文字时取最新完整回复。已保存回执的“将回复发送到另一侧”把这份准确的完整回复发送回原来源会话。
3. “交接记录”读取本机回执；“核验送达”只核对绑定目标，并显示检查中、结果或错误，不再次发送；“查看回复”展示原回答；“将回复发送到另一侧”才是真实提交。检查成功不等于反向发送。
4. 若重开后不在原页面，先在“交接记录”选中该回执，再点“打开原交接会话”。此操作只恢复记录中的两个会话，不发送；任一侧正在生成、有未保存网页草稿或附件时会阻止切换。加载完成后再点“核验送达”。
5. 目标变化、已有草稿、登录或验证问题在原处处理，草稿保留。送达未知先对账，不反复点击强行重发。历史回执始终保留原目标，不随面板改名。

### 自动互聊——默认关闭

顶部打开“自动互聊”，核对双方绑定会话，填写角色、首轮指令、往返轮次和时间预算，查看精确附件清单，点击一次“开始自动互聊”。一次往返包含两个方向交接。正常完整回复会自动交给另一方，无需逐轮点交接或检查。

“暂停”阻止下一次提交，提供方仍可能完成已经收到的请求。“继续”先核对待处理回执。“停止后续互聊”停止本次本机调度，不虚称取消远端生成。App 重开后，未结束的互聊恢复为暂停，已完成／已停止的互聊保留终态且不重放；先回到两个绑定会话再继续。自动互聊期间请求手动交接会先暂停，要求核对后再发送。

目标改变、登录验证、服务限制、附件缺失、重复回答和送达不确定会暂停。可选结束规则只识别当前回答独立的最终认输或 `STATUS: CONCEDE` / `STATUS: STALEMATE` 声明，引用和代码不触发。模型输出不能修改参与者、权限、文件范围或预算；自动互聊不授予文件执行、命令、审批或 Git 权限。

### 真实附件，不是路径

面板“附件”入口支持选择 TXT/Markdown、PNG/JPEG 和简单文字层 PDF：最多 8 个文件，单个不超过 8,000,000 字节，合计不超过 12,000,000 字节。选择只生成本机私有副本，不上传。“移除选择”不修改网站草稿。回执绑定名称、类型、字节数、SHA-256、来源和接收方。网页交接通过网站受支持的文件控件传原始字节；Codex 的独立文档提取规则不变。

上传完成、消息送达和模型内容可读分开记录。控件不支持、字节变化、网站已有附件或上传未确认时停止并说明。文件名及 `file://` 不是上传证据。各提供方实际覆盖范围以发行回执为准，不从选择框推断。提供方生成的文件须经真实下载／导出，用原生保存框保存，再明确选入另一侧；不编造下载字节，不自动分享整个项目。

### 夜璃与双侧活动

人物右下角独立的悬停“舞台”箭头，单击进入／退出透明人物舞台；标尺缩放区和滚轮独立调整大小，全屏箭头不会缩放。它与“＋”及菜单共用动作。返回、动作、姿态、声音、隐藏、退出位于顶部可见安全区，按真实 Dock 和菜单区域布局。空白区保持穿透，退出恢复位置、缩放和服装。

左侧、右侧或双方正在生成时显示对应工作状态；一侧结束不会覆盖另一侧工作。网页直接输入也被观察。阅读历史、检查投递不算工作。自动回合间调度显示排队／等待。连接未知保持中性，不假装空闲或工作；未核验、部分完成、失败和取消不庆祝。悬停、拖动和手动试播结束后恢复当时真实基础状态。

随包组件连接这个精确 TWOS。已单独运行的兼容新 Nyra，可在“夜璃状态”明确点击一次“连接”；双端真实签名核验后仅分享只读最小状态。旧的仅显示版本可能需要正常升级才能新连接，不关闭身份校验，不手工复制端点文件。

**升级结束点：** 只检查新悬停入口／顶部菜单、双向交接／自动控制、精确附件和双侧活动。不重做出行、LDD 或已通过的 Open/View/Save/Finder。
