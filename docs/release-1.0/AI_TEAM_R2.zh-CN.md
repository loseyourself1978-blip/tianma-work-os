# TWOS 1.0.13 候选版 AI Team 使用指南

在工作台顶部点 **AI Team**，再点群聊列表里的 **新建任务**。直接说明想得到什么。例如，让团队解释一段话，或将一份会议纪要整理为清单。文字任务可以在聊天里完成。需要文件时，从 **成果文件** 选择已有目录，里面可以有自己的文档。

## 在一个群聊中工作

- 创建群聊时，协调者继承左侧当时可读取的配置。打开 **成员** 可以更改姓名、提供方、可用模型、强度和职责。网页成员可先点 **打开连接**，在官方网页选好型号，再点 **采用网页当前选择**。变更从后续分派开始生效。输入框的语言选项设置本群任务的输出语言。
- 默认三位成员，最多再加三位。一人可以兼任多项职责。独立审核需要不同的制作人、审核人，以及不同模型的调用证据。执行详情会分别列出请求模型和提供方回报的模型。
- 普通消息发给协调者，用 **@** 可以指定一人或多人。通过 **＋** 选文件，也可以拖入文件或粘贴图片。群聊记录收件人、提交时的附件版本及派发回执。通道无法读取某个附件时会显示具体问题。
- 执行中，符合条件的补充可以送入本机 Codex 的指定活动轮次。发给其他成员、或不支持实时追加的通道时，消息进入对应队列。点成员消息旁的执行状态查看过程。**停止** 仅作用于当前群聊，其他群聊有自己的队列。
- 任务进行中可切换群聊或新建任务。草稿留在原群。重启后如有一条送达待确认的消息，回到原群点 **核对状态**，核对已有派发后再继续。
- 完成后可直接追问原因，也可提出具体修改来开启后续工作。主动停止后，需要明确提出继续制作。旧群聊可以在原群继续，**载入旧版群聊** 可载入早期预览记录。历史私人备注仅在本地显示。

## 查看与验收成果

打开 **成果文件** 可看到选定目录和真实文件，并可 **预览**、用系统应用 **打开** 或 **在 Finder 中显示**。成果直接位于所选目录或项目正常需要的子目录，冻结审核版本由应用保管。遇到外部编辑或另一群聊的同名文件，会显示冲突。核对原件后，可另选合适的目录保存当前成果。

审核针对冻结的内容。阻断项需要对应需求、位置、证据和修复建议。仍有实际进展时可继续第三次及以后的修订。调整策略后同一缺陷仍然存在时，会在群聊提出需要你决定的问题。接受操作针对已核对的版本。提供方缺少逐次真实型号时，执行详情记录缺口，独立审核的正式通过状态保持待确认。

## 候选与回退

R2 在配置目录的 `team-r2` 中保存新群聊，R1 原始记录保留在 `team-r1`。要回到旧界面，正常退出候选，启动保留的 1.0.12 / 101.60 正式安装版。请保留配置和所选成果目录。旧版本读取自己的历史，再次打开 R2 可恢复后续群聊。
