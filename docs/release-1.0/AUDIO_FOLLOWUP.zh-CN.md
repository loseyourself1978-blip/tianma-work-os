# TWOS 1.0.5 · 小田动作语音

夜璃会在合适的动作开始时播放内置的小田中文短句。侧卧时提醒休息，核验成功时说“欧耶！你好棒！”。默认静音；在声音面板中取消静音，打开“跟随动作说话”。点右上角“关闭”、按 Esc 或再点声音图标可收起面板。

## 开启、试听和关闭

夜璃展开菜单或透明舞台顶部 → 声音 → 中文 →「小田 · 内置短句」。取消“静音”，开启“跟随动作说话”，调整音量。选择动作后点“试听短句”。

面板右上“关闭”、Esc 或再次点击声音入口均可收起；收起面板不关闭动作语音。静音立即停止全部声音。关闭“跟随动作说话”停止自动短句，仍可手动试听。

小田用于中文固定短句。English 继续使用当前 Mac 实际可用的系统女声；不把它称为英语小田。中文列表也保留本机声线选项。已有自定义动作录音优先，静音、音量和语言偏好保留。

## 动作与短句

| 动作 | 中文 |
|---|---|
| 问候 | 嗨，我在这里，陪着你呢。 |
| 侧卧休息 | 累了吗？喝口水，休息一下吧。 |
| 工作开始 | 开工啦，我陪你一起加油。 |
| 等待确认 | 需要你确认一下哦，我在这里等你。 |
| 核验成功 | 欧耶！你好棒！ |
| 失败时鼓励 | 别着急，我们慢慢来。 |
| 换装 | 换好啦，好看吗？ |
| 挥手或悬停短动作 | 嘿，我在呢。 |

仅在合适的动作开始时播放一句；不持续循环。全局冷却 10 秒，同类短句 45 秒，休息/挥手 120 秒。不叠音，不排队补播隐藏或静音期间的事件。首次连接和重连不回放旧工作或庆祝。部分完成、取消、未核验或失联不庆祝。手动庆祝只是试听，不改变业务接受。

本轮选定 [TTSMaker](https://ttsmaker.com/zh-cn) 的 1413 默认音色，使用免费生成；不使用 Pro 情感选项，不购买服务。生成只提交上述固定台词，不提交聊天、任务或其他私人内容。两款安装包内置相同的八段实际录音，本机动作播放不访问 TTSMaker、不消耗在线额度。

## 自定义与恢复

选择语言及具体动作 →“导入此动作音频…”→ 选择可播放、少于 25 MiB 且不超过 120 秒的录音。文件仅保存在本机，不上传。导入失败不覆盖原录音。

“恢复此动作女声”只移除当前语言/动作的自定义录音；中文选择小田时回到内置对应短句。旧通用导入只用于问候，不自动复制到各动作。内置文件缺失、损坏或校验失败会明确提示，不会悄悄改播另一种女声。

安装实际交付的新候选后，只需：中文试听“休息”“庆祝” → 关闭面板 → 开启动作语音，试一次侧卧和手动庆祝。留意冷却时间。原 Nyra、辩论、出行网页和成果操作接受均保留，不重新制作或重跑业务。
