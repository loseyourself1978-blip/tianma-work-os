# 夜璃：简洁任务状态与返回 TWOS

候选标识：1.0.11 / build 101.59。尚未发布。

候选差量：NYRA-MINIMAL-STATUS-FOCUS-AND-R0-BOUNDARIES-R1。验证和发布尚未完成；本页不是新版本公开下载或 Owner 验收回执。

## 人物下方显示什么

紧凑气泡只显示已观察到的当前活动：提供方、有限长度的任务标题和真实状态。两侧同时活动时各占一行并标明左右；长标题截断，不挤掉状态。不调用模型生成任务摘要。确认空闲、完成、失败或取消后收起。短暂失去观察时显示“待确认／待更新”，关闭任务操作，并在有限宽限期后收起，不无限保留旧任务。只读状态可信时，即使没有编辑授权或控制连接暂不可用，也可继续显示活动。

悬停显示已有的编辑和停止按钮。两个任务时通过选择器确认操作目标；点击某一行只定位该行准确绑定的任务。无法核对目标时给出短暂更新提示，不静默跳往别的任务。已结束任务的可编辑草稿仍可从夜璃菜单按需打开，不常驻空闲气泡。保留用户明确隐藏任务标签的选择。

## 单击人物返回

单击人物请求恢复准确认证的正在运行 TWOS 工作台；不要求有任务或编辑权限。拖动只移动，任务操作按钮不触发人物跳转。宿主检查正确窗口实际可见、非最小化、激活且取得焦点；不以 activate 返回成功代替真实窗口状态。

新增仅聚焦通道与任务控制通道分开。它只接受聚焦元数据，不接受任务、草稿或命令。保留同一用户、准确应用路径、签名、真实运行对端和宿主实例核验，I/O 与身份校验不阻塞 UI。旧宿主可使用有期限的原无任务目标聚焦请求；不支持或未确认时诚实报错。

若另一安装副本的夜璃仍在运行，从那个夜璃自己的菜单正常退出，再在要使用的 TWOS 中显示夜璃。不删除用户配置、不强退其他应用。内置版可重新核验固定签名父应用以接续重启／更新；独立版不会静默换安装副本或增加编辑权限。

## 反馈、草稿和权限

连接／聚焦错误只在相关操作后短暂按语言提示，并可在 TWOS → 更多 → 夜璃状态查看。人物上方不再常驻诊断横幅。没有编辑行为时，普通连接错误不会无依据声称“输入已保留”。真正的草稿恢复数据及不确定发送保护继续保留，不自动重发。

只读状态、宿主聚焦和任务修改相互分开。任务操作还需匹配认证宿主、当前状态会话／轮次、准确目标、权限和请求身份；标题相同不等于同一个任务。旧宿主缺少新绑定信息时，气泡操作安全退化，不猜目标；普通返回和只读展示仍独立。

编辑入口保留键盘焦点、中文输入法、取消与草稿能力。Steer／Queue、仅修改未发内容及审批边界仍由 TWOS 控制。停止先阻止关联队列／接力后续派发，再中断准确任务。“正在停止”不等于已取消；收到真实终态后默认活动气泡收起，最终结果或未确认停止在 TWOS 查看。夜璃不能批准、执行 shell、扩大目录或接管官方客户端控制中的会话。

状态通道仅包含有限标题、状态与不透明标识，不包含正文或文件。控制通道只传用户主动编辑的文本／操作；宿主聚焦不传任务内容。共享屏幕前可隐藏任务标签。

## 验证边界

新候选仍需实测左右及双方活动、结束收起、控制断连、宿主重启，以及 20 次真实单击的场景和延迟。暖连接目标为 1 秒内，不是已经达到的结果。多屏／Space／全屏必须记录实际覆盖。历史点击通过和协议测试不能替代本候选 GUI 验证。
