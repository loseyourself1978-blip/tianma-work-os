# TWOS 1.0.4 / 101.52 — simplified handoff

Applies to this R4 candidate and its pinned Nyra 1.0.3 / 103. Build, complete-gate, signature, notarization and publication status are identified by the matching release receipt, not by this guide alone.

## A · Existing users: check only the new controls after upgrading

Entry condition: verify the matching release receipt, signature, notarization and downloaded hash before installation. Quit the old TWOS/Nyra normally, then replace the appropriate app. TWOS includes its matching Nyra; a separate companion installation is not required. Keep sign-ins, chats, drafts, folder permissions and pet preferences.

1. Chat normally in the two selected website conversations. No current Send/readiness card appears during thinking, generation or tool activity. Once the existing checks confirm a complete reply, that pane shows one **Send to {opposite provider}**. Click once. **Sent** is the receipt; checking delivery is not another required step.
2. For continuous conversation, check **Automatically send replies to {opposite provider}** on either side. Both checkboxes mirror one session, seeded by that side's current new reply. Wait for generation to complete, or for a new reply if none exists. A matching sent/in-flight reply is reconciled, never sent twice. There is no role, first-message, round or minute form.
3. Click **Stop auto-send** in the same primary-button position, or uncheck either side. A provider's native Stop also revokes future sends for both participants, including between turns. An already sent message cannot be recalled; a late reply cannot schedule another turn. Auto-send stays off after reopening the app.
4. **⋯ More** contains Open in Safari, original TWOS projects, attachment selection/removal, handoff history and diagnostics. Only explicitly selected files are in scope; a filename/path is not upload proof. Stop auto-send before changing files.
5. Nyra hover controls contain only **+ / Expand** and the actual character-stage button. Expanded controls offer **Larger / Smaller / Reset size**. Wheel/trackpad resizing remains. The old ruler/square drag grip and its hit region are removed.

6. The top **Language: English / 语言：简体中文** selector changes TWOS controls immediately and saves the preference after reopening. Provider website language and conversation text stay unchanged.
7. Click **Show Nyra** to display the matching companion; the same button becomes **Hide Nyra**. Click it again to hide. An incompatible helper from another installation is explained instead of reporting false success.

End point: report only the visibility/usability of these new controls. Do not proceed into the first-use route below or re-prove accepted business work. Only the Owner grants new UI acceptance.

## B · First use

Only for new users. Follow the matching installation guide to verify macOS/architecture coverage and SHA-256, then install the signed, notarized TWOS. Sign into the official websites directly; credentials and human verification remain with the user. TWOS does not copy account credentials.

Select each provider and exact conversation. Chat normally, then Send below the complete reply, or enable automatic replies and stop from either side. Local Codex execution still requires its separately bound folder and existing approvals. Website auto-send grants no file, command, approval or Git rights. If using original local projects, their existing email registration/verification/sign-in route remains unchanged.

End point: understand the selected content, recipient and Stop control. No demo website or repeated report is required.

## C · Continue existing work

Select the original providers/conversations and retain drafts, file records and folder bindings. Refresh/reopen restores observations; it does not replay work. Auto-send is off until explicitly enabled. For uncertain delivery, open **More → Handoff history** and inspect the exact receipt. Inspection does not resend.

If a matching manual handoff is in flight, checking auto-send reconciles it and continues from its real reply. Old/new topics and diagnostic text are not interchangeable “last text.” If a changed target, sign-in/challenge, quota, draft conflict, missing file or repeated output pauses the exchange, resolve that stated cause before explicitly continuing.

## Permissions, results and troubleshooting

TWOS uses existing official website interactions in WKWebView and its Codex App Server client; it does not embed the complete official Codex GUI. A manual send/shared automatic session freezes the selected message identity, body version/hash, files and both destinations. A peer's response cannot expand permissions or recipients. No automatic purchase, recharge or billing-path switch occurs.

Unknown/interrupted replies are not declared complete. Uncertain delivery is reconciled before retry; sign-in/challenges use the website's normal process. Transport completion, business result, verification and Owner acceptance remain separate. Nyra reads minimal state, never message/file contents, accounts or credentials; it cannot execute or approve work.

If Send is absent, check whether the reply is still generating, interrupted or has a stated observation problem. There is no header Send to repeatedly click. Use Details or More → Handoff history for evidence. An in-flight reply finishing after Stop does not mean another turn was dispatched.

macOS only. Windows is in development with no downloadable version. Matching media and measurement coverage are listed in MEDIA.en.md and the release receipt. Historical R3 screenshots are not R4 UI evidence.

**Show Nyra / Hide Nyra** follows the observed bundled companion window. A helper from another installation is identified as a conflict instead of pretending to be hidden; quit that Nyra normally from its own menu, then show the current bundled component. No running task is stopped.
