# 隐私、权限与费用

适用于 TWOS 1.0.3 / 101.51。升级后先看 [R3 差量指南](OWNER_REGRESSION_R3.zh-CN.md)，完成对应终点即结束；不重新制作已接受任务。



[R2 差量操作和准确边界](BIDIRECTIONAL_R2.zh-CN.md)。


TWOS 承载供应商官网，并连接本机 Codex App Server。各供应商遵循自己的账号、留存、计划和用量规则；TWOS 不把所有服务强行合成一个额度池，也不静默变更计费路径，不自动购买、重置或订阅。

只向明确绑定目标发送选定正文/附件。选择文件夹不等于读取全部正文；本机执行限制在确认范围内，真实批准请求保留。HTML 成果在产品认证主页面/原生桥之外打开。

Nyra 仅接收有界只读状态和不透明关联标识，不接收聊天、代码、账号、凭据或业务账本。它不能执行、批准、交易或发消息；保留签名和对端身份核验。偏好与 App 源码分离，公开诊断必须脱敏。

普通本地动画不要求辅助功能、全盘、麦克风、录屏或全局键盘权限。用户选择受保护目录时可能出现文件夹许可；截图/录屏属于另行授权操作。不静默创建系统登录项。

[English / 简体中文](PRIVACY_AND_PERMISSIONS.en.md)


自动互聊只在本机私有工作台配置中保存明确授权的指令／回复和精确选定文件副本。选择与向提供方上传分开。Nyra v2 只读通道仅增加 `activity_side`（左／右／双方），不含文件字节、正文或账户。独立版接续须明确确认并核验真实对端。状态读取不会创建模型轮次。
