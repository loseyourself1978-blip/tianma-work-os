## 讨论、交接与结果

服务选择器决定真实接收方，只发送明确选定的正文/附件。已就绪且支持的网站目标可单击提交；草稿、待登录、真人验证、送达未知分别显示。未知状态先对账，不盲重发。网页返回代码不等于本机已生成文件；交 Codex 落盘属于另一项交接。TWOS 使用原生 WKWebView 与 App Server 客户端，并非嵌入官方 Codex macOS 整个 GUI。

右侧可展开真实工具活动、命令、输出、diff 和批准。额度区分账户窗口与本任务观测 Token。已运行时间不是计费计算时间；ETA 是标明依据的本地估计，证据不足会解释。执行通道、业务结果、验证结论和 Owner 接受是不同状态。

成果卡分别提供“打开网页”（可信宿主打开确切授权文件）、“查看文件”（阅读）、“另存为…”（选副本位置）、“在 Finder 显示”（定位原文件）。单文件任务只有一个成果是正确结果。不可信 HTML 不进入带产品会话和原生桥的主页面。

## 夜璃

顶部“显示/隐藏夜璃”控制浮窗。移入人物跳一次；向左/右拖动播放相应跑动，松开落定。桌面控制环和舞台共用受控手动试播，试播庆祝不写业务成功。

黑紫、职场、晚礼服均有站姿和侧卧。“舞台”打开透明屏幕尺寸舞台，“姿态”切换站卧；卧姿跑跳使用同衣服起身/动作/躺回素材。空白区域允许操作下层窗口。“桌面”或舞台有焦点时 Esc 返回原位置、比例和服装；隐藏/退出也恢复。没有全局键盘监听。

Nyra 只读最小状态。空闲、运行、排队/等待、partial/失败/取消和失联分别显示；未核验完成不庆祝。确切绑定的单次成果明确核对后可庆祝一次，不改写原执行器 PARTIAL，也不代表整个产品接受。重连不重播庆祝。

夜璃有13段内置小田中文录音，以及13句由本机女声朗读的对应英文台词；在符合条件的待机、阅读、工作、休息、核验成功等动作开始时播放，带冷却避免重复说话。默认静音；在声音面板中取消静音，打开“跟随动作说话”。点右上角“关闭”、按 Esc 或再点声音图标可收起面板。

## 工作台语言与夜璃显示

顶部直接显示 **Language: English / 语言：简体中文** 选择器，切换后 TWOS 控件立即更新并保存偏好。不会改变提供方账号语言、任务正文、聊天或文件，不会发送任务。

**显示夜璃／隐藏夜璃** 跟随实际内置浮窗状态。若另一安装位置的夜璃仍在运行，会明确显示冲突，不把它当成已隐藏；从该夜璃自己的菜单正常退出后，再显示当前内置组件。不会停止任务。
