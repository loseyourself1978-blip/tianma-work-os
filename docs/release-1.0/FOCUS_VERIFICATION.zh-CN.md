# 聚焦与任务控制——验证范围

TWOS 1.0.10 / 101.58；Nyra 1.0.7 / 107。运行时代码来源：TWOS `70272fe9820b3b668b770960d42c15204a7d1da1`，Nyra `a897169abfae4eb4535940420097ff9dbdf621a1`。文档提交可晚于这些运行时提交。准确制品 hash、签名与公证标识见匹配发行回执。

## 发现与修复

- 原人物点击只请求激活应用，没有证明正确工作台已经显示；鼠标命中依赖定时刷新，快速移入可能早于下一次更新。现以鼠标移动事件补充定时器，并通过独立认证宿主请求恢复准确工作台，核对实际活动、可见、未最小化和 key 状态。签名与端点工作在交互线程之外执行。原有首鼠实现保留，不以重复添加首鼠声明代替修复。
- 原只读标签没有任务控制入口，人物窗口也不能取得键盘焦点。新两行气泡直接提供铅笔和停止；独立可成为 key 的输入窗口冻结任务身份，支持中文输入法及原生编辑快捷键，保留草稿／恢复内容，只编辑未发送队列项。
- 候选实测发现：迟到的历史分页响应将新派发、由本机持有的输入误判为未知投递。现保留该准确在途身份，同时继续约束外来输入、投递未知、范围变化和已停止任务。
- 早前 N/O 的“点击无反应”原记录保留，未声称完全定位原始点击链。已确认反馈缺陷是常规轮询擦除在途状态、重新启用按钮。现用请求及目标绑定的停止记录、即时持续“正在停止”、防重复、有界“未确认”及终态后才显示“已停止”，不自动重试。
- 保存的 turn 摘要不足以提供官方 App 活动会话的最新公开消息。现按稳定消息身份有界分页读回；左右侧共用项目／会话侧栏，移除会话下拉框。官方未暴露的项目成员关系使用明确标注的目录分组；不冒充完整官方 UI，不接管其活动会话。

## 自动化证据

同一批串行 TWOS 完整门禁：1873 通过、1 项明确保留的历史跳过、0 失败；38 项真实 Safari 测量均在可见状态开始和结束，运行时及冻结输入 hash 在该批运行期间未变化。发行文档及回执随后更新并单独核对，不冒充此前完整门禁的输入。此前失败／部分批次不并入此结果。

独立 Nyra 生产 AppKit／控制套件针对最终控制源码完成 19 项，耗时 15.838 秒。其服务边界为模拟，覆盖关联、过期回调、首鼠、输入恢复和停止反馈，不能替代下述真实操作。内置与独立候选的 15 个 Swift 源文件和 189 个资源文件经 hash 核对一致。新 App／DMG 分别完成签名、公证与 Gatekeeper；只读挂载 DMG 的文件清单与签名 App 一致。
