# TWOS 1.0.13 / 101.61 · AI Team 群聊与直接交付

在工作台顶部进入 **AI Team → 新建任务**，输入目标或附加说明。一个输入框可发送普通消息，也可用 @ 选中一名或多名成员。默认三名成员，最多六名。不同群聊可并行工作。在 **成果文件** 选择现有文件夹，完成的文件直接出现在该目录。
