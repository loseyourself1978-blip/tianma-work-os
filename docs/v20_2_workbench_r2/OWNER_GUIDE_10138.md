# TWOS 101.38 单窗口工作台操作指南

此指南对应 101.38 单窗口候选。工程验证已通过，Owner 验收仍待进行；101.37 的两个 App 并排方案已撤下。

## 安装这一版

1. 使用同一交付文件夹里的 **Tianma-Work-OS-1.0.1-build-101.38.dmg**，先查看 **START_HERE.md** 的版本、验证状态和 SHA256。不要继续安装已撤回的 101.37。
2. 等旧 TWOS 的任务完成并保存，再正常退出旧 TWOS。保留现有 App 备份及项目数据；不要删除“资源库”中的 TWOS 环境文件夹。
3. 双击 DMG，在 Finder 中把 **Tianma Work OS.app** 拖入 **应用程序**。如果 Finder 提示同名 App，由你确认是否替换旧 App。本轮开发不会自动替换你的安装。
4. 从“应用程序”打开 TWOS。应出现标题为 **TWOS** 的一个窗口，里面同时有左右两个服务面板。此版不需要辅助功能权限来排列其他 App 的窗口。
5. 若 macOS 提示无法验证或阻止打开，保留提示并反馈；不要修改系统安全设置或用终端绕过校验。当前候选是本机验证签名，不是已公证的公开 GA 安装包。

首次使用前，本机需要已有官方 Codex App，并已在其中完成正常登录。TWOS 使用该本机工具及已有账号，不要求你另购 API key。

## 打开与账号

打开 TWOS 后，一个窗口里显示两个面板。默认左侧为 ChatGPT 官网，右侧为本机 Codex 会话。可拖动中间分隔线调整宽度。

左侧直接使用 ChatGPT 官网的模型、历史、输入框、附件和发送按钮。首次请在官网登录你的 ChatGPT 账号；不要在聊天中粘贴账号密码。已经在此 TWOS 浏览器登录过的账号会使用原浏览器配置。官网若要求重新验证，按官网提示操作。

这个入口不需要先选 你原先使用的环境，不需要重新注册 TWOS，也不需要 iCloud App 专用密码。旧 TWOS 的邮箱绑定仍保留。

## 接入原本机 Codex 会话

1. 在右侧点击 **连接本机 Codex**。
2. 在 **会话** 下拉框选择要继续的已有会话；更多会话可点 **更多会话**。先核对下方工作目录和历史。选择会话只读取内容，不开始任务。
3. 要在 TWOS 中继续执行，请先正常退出原 Codex App。TWOS 使用同一个会话 ID 和工作目录接续；不要让两个客户端同时执行同一会话。
4. 模型下拉框来自当前本机 Codex 服务，也可沿用会话模型。额度由现有官方账号决定，TWOS 不设额外调用次数，不购买额度。

当前入口接续已有本机会话。如果还没有目标会话，先在官方 Codex App 中打开所需项目并建立会话，再返回 TWOS 连接；不要把私人项目选作随意的测试目录。下方显示的目录就是实际执行位置，不再要求填写旧版的“隔离样本路径”。

右侧通过官方 Codex app-server 协议显示真实会话、输出和审批。它不是将 Codex App 原生窗口嵌入，也不声称复制了原 App 的全部功能。

本版连接默认只允许在所选会话工作目录内开发；不继承原 App 的插件、MCP 服务或多代理设置，不自动开放网络或 Git 写入。命令、文件操作需要审批时会直接显示真实请求；专门的工作区权限扩张请求目前只能拒绝。需要这些扩展能力的任务尚不属于本版已验证范围。

## 从讨论到执行，再回到讨论

1. 在左侧原讨论中说明需求，例如：
   > 把出行清单做成手机可用的网页，支持添加、勾选、删除和刷新保留。在本机制作，不发布。请先和我确认需求，再整理一份完整的 Codex 执行指令。
2. 讨论确认后，点击左侧顶部 **交给另一侧**。有选中文字时传递所选内容；在 ChatGPT 中未选中文字时，使用当前对话最后一条助手回复。
3. 指令出现在右侧输入框，可以修改。核对目标会话和工作目录后，点击 **交付 Codex 执行**。
4. 右侧直接显示 Codex 输出、公开思考摘要、命令结果及文件改动。需要你决定时，在对应卡片中批准、拒绝或回答。没有“准备 → 批准 → 开始 → 独立复核”的额外固定流程。只会显示供应商实际提供的思考摘要，不补写隐藏推理。
5. 完成后点击 **将结果带回原讨论**。结果会填入发起交接的那段官网讨论输入框，保留已有草稿。核对后用官网的发送按钮继续讨论。
6. 新一轮指令仍交给同一个右侧会话即可迭代。点击 **打开工作目录** 可在 Finder 查看实际文件。

两侧不会在后台自动交换全部历史。交接传递你选定的指令；回传使用该次完成任务的结果，并检查来源讨论地址。如果左侧换了另一段聊天，请先回到原讨论再回传。

## 切换面板与后续服务

窗口顶部的左右下拉框可以选择 ChatGPT、Codex、Claude、DeepSeek 或 **网站…**。网站项接受 HTTPS 地址，也接受显式填写的本机 localhost 看板地址。

Claude、DeepSeek 是官网入口预设，需要各自正常登录；本轮尚不将它们的登录、发消息或跨站协作列为已通过验收。非 ChatGPT 网站请先选中要传递的指令。官网输入框结构变化时，自动填入可能不可用，TWOS 会明确提示，结果仍保留。

尚未接入具体 LDD 持仓看板或读取任何持仓资料。后续可为用户明确授权的看板配置网站面板；不会因存在“网站…”入口自动访问财务资料。

## 关闭、重开与失败恢复

- 日常关闭窗口后，可点 Dock 图标或菜单 **Window → ChatGPT + Codex** 返回。
- 退出 App 前先停止或完成当前任务。TWOS 不承诺退出后后台持续执行。
- 重开会恢复面板配置和官网地址。连接右侧后恢复原会话及草稿；已完成任务的原讨论绑定可从保存记录恢复。
- 连接错误会直接显示说明；**消息详情**可展开实际错误，不需要寻找隐藏的 JSON。
- 执行中断或结果未确认时，不会自动重发。使用 **重新连接并查看** 检查已保存历史；在最终状态仍不确定时，TWOS 会保留草稿并阻止重复执行。
- 官网额度与登录要求仍由官网管理；本机 Codex 额度与错误由实际服务返回。

## 旧账号与旧项目

点击 **原有 TWOS 项目**，选择此前的环境（例如 你原先使用的环境），点击 **打开所选环境**。不要为了新版重复创建旧账号或重跑原任务。

这一入口保留旧版本的本地邮件配置和项目数据。本轮不改变已接受的 101.26 交付，不自动替换正在运行的 Owner App。App 的打开、连接和交接按钮不会自动 Commit、Push、Tag 或公开发布；开发仓库的本轮 GitHub 同步按 Owner 单独提出的要求处理。
