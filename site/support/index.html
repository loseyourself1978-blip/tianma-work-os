Help & troubleshooting

TWOS support

Start with the guide for your installed version. For a product problem, use the public project issue tracker.

Report a TWOS issueReport a Nyra issue

Published by Jing Huang. Issues are public and require a GitHub account to post. Reading the guides and existing issues does not require signing in. No response-time guarantee is offered.

Keep private information private

Include the app version/build, macOS version, affected provider, steps and a short description of what you expected. Use a new, non-sensitive example when possible.

Do not upload passwords, tokens, cookies, account details, private chats, personal documents, local databases or unredacted diagnostic archives. Crop screenshots to the relevant control. For a sensitive matter, post only a request for a private contact method, without the sensitive information.

Finish or stop your active task, quit normally, then replace the app using the verified installer. Do not delete your data or recreate a completed task just to upgrade.

AI Team group chats

Open AI Team in the toolbar and select New task. Type your goal or attach a brief. Mention a member to direct a question. Open Files to choose an existing output folder, preview a file, or show it in Finder. Return to a saved chat to continue working. For a paused first message, choose Refresh connection. If the chat asks you to sign in, use the member’s own window, then choose Back to chat · Check connection. Select Continue queued message when ready. Use Continue once to skip repeated copies. If delivery is uncertain, check the original operation.

Selecting Codex on either side of the workbench starts a connection. Retry connection becomes available if the attempt fails.

Local Codex connection

Choose Codex on the left or right to start the connection. The workspace remains responsive; Cancel connection is available while startup is pending. Missing executable, authentication, timeout and process-exit errors have distinct recovery messages. Sign in through your official local Codex app when required, then reconnect explicitly. Connecting does not send a task. Never resend a task whose delivery is uncertain.

Nyra 1.0.8 is included. Use Show current tasks to show or hide fresh task labels; click the character or label to return to the authenticated running TWOS host. If the host cannot be verified, reconnect rather than opening an arbitrary application.

If a handoff pauses

  1. Check the displayed destination and the selected conversation.
  2. Look for login, verification, a draft conflict, quota or delivery-status messages. Complete website security checks yourself.
  3. Open handoff history from ⋯ More. A check observes the existing delivery; it is not a reason to resend uncertain work.
  4. Stop automatic replies before changing participants. Do not repeatedly send the same task when its delivery is unknown.

The preserved 1.0.6 / 101.54 repair covers auto-send intent projection, native Stop, interrupted replies and replacement composers. Both initiating providers exceeded five real round trips in dedicated tests; the original Owner first-round trigger was not reproduced. Preserve any new failure receipt and do not blindly resend uncertain work.

TWOS 1.0.14: Nyra activity and task controls

This version uses a direct pencil and Stop on a compact task bubble. Standalone Nyra first connects through ⋯ More → Nyra status → Connect and authorize; an existing visibility-only connection uses Enable Nyra task controls…. Check the exact host before confirming. Official-app active runs stay read-only. An unconfirmed send cannot be retried automatically; preserve the draft and inspect its original receipt in TWOS. Stop immediately shows Stopping; confirmed cancellation changes it to Stopped. If confirmation is missing, inspect the exact task in TWOS without repeatedly retrying.

Missing activity or a character click that does not return

No current task means no default bubble. Short status gaps show an unconfirmed state and then close; they are not reported as idle or left running indefinitely. Viewing trusted activity and returning to the workbench do not require edit permission.

If Nyra reports another installation, an older engineering helper may still occupy the single companion instance. Quit that Nyra from its own menu and show Nyra from the intended TWOS. Do not force-stop another app or delete profiles. Reconnect after a host restart if identity cannot be verified; no arbitrary second TWOS installation is opened. Error details are available in TWOS rather than a permanent banner over your work.

Sound and Nyra

In Nyra’s Sound panel, unmute and enable action voice. Chinese keeps the 13 Tian recordings; English uses 13 matching tiny-voca F2 American English recordings. Both play offline, with cooldown and no overlap. Installed system speech is a fallback, not a guarantee of a particular voice. Close the panel with Close, Escape or the Sound control again. A pet animation is not a certificate of task success.

Data and service accounts

For local-data removal, stopping sharing and provider deletion requests, see the privacy page. Website accounts, subscription charges and provider-side retention are handled by the relevant provider. TWOS support does not need your login credentials.
