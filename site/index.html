Start with a goal

Choose AI Team → New task. Type a question or attach a brief. Start with three teammates, add up to three more, and assign responsibilities in Members. Return to a saved chat to ask a follow-up or request a revision.

Keep working in the same team conversation across turns. A group member can follow the website’s model selection or keep a named model. The two-pane workspace routes a reply to the identified discussion and preserves other drafts.

If a website keeps a draft, choose Check original conversation. TWOS looks for a matching sent message or an unsent draft. When a local builder has already finished, you can recover its files and pass that version to review.

Separate chats can work in parallel. Open Files to preview a result, open it in another app, or show it in Finder. The team saves output directly in the folder you choose.

Choose your pairing

Choose ChatGPT, Claude, DeepSeek or local Codex from the service selectors on either side. Use two website conversations to compare and refine ideas, or pair a website with Codex for local development. Each service keeps its own model choices, account and limits.

Actual TWOS 1.0.16 windows, November 23, 2026. Web services are signed out. Claude shows its sign-in or verification screen. Local Codex is unavailable in this isolated capture profile.

Choose how the conversation continues

Website pairs: send a complete selected reply manually, or enable automatic replies for a supported ChatGPT, Claude and DeepSeek pair. Either side can stop future sends. Login, verification, drafts and service limits can pause the exchange.

Pairs with Codex: local execution requires your installed, signed-in Codex, a confirmed workspace and the applicable approval. Website auto-send does not authorize commands or file changes. Choosing a service does not start a task.

These are the supported integrations shown here, not a claim that every model or arbitrary website supports automated handoff. TWOS provides its own Codex client; provider interfaces and availability can change.

Your task, your scope

A web reply containing code is still a reply. Writing files requires a separate, authorized local execution path. Choosing a folder does not grant permission to read every file inside it.

TWOS provides its own client for the official Codex App Server protocol. It does not embed the full official Codex application interface.

Nyra activity and focus

Nyra now separates current activity from task controls: only active work appears by default, completed work closes, and a brief observation gap is marked unconfirmed. Character return uses an independently authenticated host-only connection. Persistent diagnostic banners are removed from above the character; details remain available on demand.

Chinese Tian stays unchanged. English adds 13 matching tiny-voca F2 American English action recordings, played locally without sending task text to a speech service. The five outfits are unchanged.

Before you install

Preserved from 1.0.9: open an explicitly selected private-network HTTP dashboard in either Website pane. Invalid addresses stay editable with a specific reason; Cancel preserves the existing pane. HTTP is limited to the selected private/local host and port. Opening a page never starts a model task or shares its contents.

Preserved from 1.0.8: local Codex restores long conversations using compact history summaries. Expand Saved activity to read one bounded page at a time. A connection or history read never sends or replays a task.

Preserved from 1.0.7: connect to local Codex without blocking the workspace. Startup is cancellable, failures have bounded deadlines, and reconnect never silently replays a task. Nyra adds optional current-task labels and click-to-return to TWOS.
