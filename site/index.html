Your task, your scope

A web reply containing code is still a reply. Writing files requires a separate, authorized local execution path. Choosing a folder does not grant permission to read every file inside it.

TWOS provides its own client for the official Codex App Server protocol. It does not embed the full official Codex application interface.

Before you install

  1. Use the release page above. Download the DMG and its matching SHA256SUMS, then follow the verification and installation guide.
  2. The current direct package is for Apple Silicon macOS. Its release receipt records tested OS versions, signature and notarization details. Windows is not available.
  3. Provider accounts and usage are separate. TWOS does not include a provider subscription or buy credits automatically. Local Codex execution requires your separately installed, signed-in Codex.

Continuity repair in 1.0.6: automatic-send intent stays separate from waiting and reconciliation. Real pauses show a cause; either side’s Stop revokes future dispatch. Dedicated tests exceeded five round trips from each provider. The original first-round trigger was not reproduced, so no single cause is claimed for that incident. Inspect uncertain delivery before any retry.
