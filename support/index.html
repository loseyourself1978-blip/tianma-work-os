Help & troubleshooting

TWOS support

Start with the guide for your installed version. For a product problem, use the public project issue tracker.

Report a TWOS issueReport a Nyra issue

Published by Jing Huang. Issues are public and require a GitHub account to post. Reading the guides and existing issues does not require signing in. No response-time guarantee is offered.

Keep private information private

Include the app version/build, macOS version, affected provider, steps and a short description of what you expected. Use a new, non-sensitive example when possible.

Do not upload passwords, tokens, cookies, account details, private chats, personal documents, local databases or unredacted diagnostic archives. Crop screenshots to the relevant control. For a sensitive matter, post only a request for a private contact method, without the sensitive information.

Install, update and resume

  • Latest public release and verification files
  • First installation
  • Daily use and existing tasks
  • Upgrade and uninstall

Finish or stop your active task, quit normally, then replace the app using the verified installer. Do not delete your data or recreate a completed task just to upgrade.

If a handoff pauses

  1. Check the displayed destination and the selected conversation.
  2. Look for login, verification, a draft conflict, quota or delivery-status messages. Complete website security checks yourself.
  3. Open handoff history from ⋯ More. A check observes the existing delivery; it is not a reason to resend uncertain work.
  4. Stop automatic replies before changing participants. Do not repeatedly send the same task when its delivery is unknown.

A reported ChatGPT–DeepSeek first-send interruption is being investigated for the next direct-download repair. The current public release remains 1.0.5 / 101.53.

Sound and Nyra

In Nyra’s Sound panel, unmute and enable action voice. Current bundled Tian recordings are Chinese; English uses an installed macOS system voice. Close the panel with Close, Escape or the Sound control again. A pet animation is not a certificate of task success.

Data and service accounts

For local-data removal, stopping sharing and provider deletion requests, see the privacy page. Website accounts, subscription charges and provider-side retention are handled by the relevant provider. TWOS support does not need your login credentials.

Mac App Store submission is in preparation. There is no current Store review approval or Store download to troubleshoot.
